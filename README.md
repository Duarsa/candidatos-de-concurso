
# Sistema de Candidatos de Concurso

Projeto desenvolvido em Java para cadastro, leitura, processamento, busca e ordenação de informações de candidatos de um concurso.

## Sobre o projeto

O sistema trabalha com registros de candidatos contendo informações como número de inscrição, nome, idade, quantidade de dependentes e pontuação.

Os dados são armazenados e processados pelo programa, permitindo realizar consultas e organizar os candidatos de acordo com critérios definidos.

## Informações dos candidatos

Cada candidato possui:

- Número de inscrição
- Nome
- Idade
- Número de dependentes
- Pontuação

## Funcionalidades

- Leitura de candidatos a partir de arquivo.
- Criação de objetos para representar os candidatos.
- Armazenamento dos candidatos em uma lista.
- Busca de candidato pelo número de inscrição.
- Busca utilizando recursividade.
- Ordenação dos candidatos.
- Processamento dos critérios de classificação.
- Aplicação de critérios de desempate.

## Critérios de classificação

A classificação considera:

1. Maior pontuação.
2. Em caso de empate, menor idade.
3. Em caso de novo empate, menor número de dependentes.
